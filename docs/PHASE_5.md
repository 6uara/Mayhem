# Phase 5 - Visual identity

Implementation of the design handoff (`DESIGN_BRIEF.md` + four SPEC files + `theme_tokens.gd`).
This document records what was built, what deviates and why, and what is still open.

## The contract

`theme_tokens.gd` is autoloaded as `Tokens`, registered ahead of `EventBus` so every system can
read it. **Never hardcode a colour, size, threshold or timing that exists in Tokens.**
`tests/unit/test_spec_conformance.gd` enforces the values that live outside the token file -
enemy colours and heights, dash charges, shop timer, leaderboard path, settings defaults - so
tuning a number in a scene can no longer silently diverge from the spec.

## Done

- **Fonts** - Archivo (variable) and IBM Plex Sans/Mono, both SIL OFL, bundled in
  `res://ui/fonts/` rather than relying on system fonts. A test asserts Archivo still exposes
  its width axis, because the whole broadcast look is `wdth 125` and losing that axis would
  silently render the game in a different typeface.
- **Theme** - `ui/mayhem_theme.tres`, generated by `tools/build_theme.gd` from the tokens so it
  cannot drift. Twelve type variations map the handoff's type roles onto Label and
  PanelContainer, so a cluster sets `theme_type_variation = &"NumPrimary"` instead of
  overriding fonts by hand.
- **ChamferStyleBox** - Godot only offers rounded corners and the style guide bans radius
  outright, so the panel look is drawn by hand: flat fill, thin border, one 45-degree cut on
  the bottom-right, an optional accent rail and optional corner ticks. It is still a StyleBox,
  so Controls theme with it normally.
- **Icons** - all 25, drawn procedurally on the spec's 64x64 grid with a 4px stroke.
  Assigning `texture` on a `MayhemIcon` swaps in a hand-authored PNG later with **no change at
  any call site**.
- **Reticle** - crosshair and hitmarker merged into one system, because the handoff is explicit
  that ADS sights are screen-space Controls drawn by the same code. All five crosshair states
  plus all four weapon sights - including the shotgun ring whose radius *is* the pellet spread
  and the SMG wings that splay with sustained fire.
- **HUD** - the spec's node tree. Six corner-anchored clusters, so ultrawide pushes them apart
  rather than stretching them. Wave and enemies-left, wave timer against par, no-damage status,
  currency and power-up chips, health with a draining ghost segment, dash pips, the ability bar,
  ammo with pips, the weapon list, subtitles and announcements.
- **States** - low health (colour + breathing frame + CRITICAL tag), low ammo (colour + blink +
  RELOAD prompt), elite stripe, damage vignette, and directional damage chevrons at a fixed
  radius from centre.
- **Host layer** - three subtitle tiers (standard / warning / punchline), the crossed-ring mark
  drawn from two primitives, and the persistent broadcast bug. `NarratorManager` now enforces
  the voice rules: one line per 20 s of combat, one punchline per wave.
- **Enemy identity** - the five spec colours and heights, with proportions that put every
  archetype in a different silhouette rectangle.
- **The Healer's halo and tether**, which closes the gap flagged in Phase 3. It is not
  decoration: Ranger and Healer share body proportions by design, and the ring is what separates
  them at range and marks the priority target over cover and through crowds.
- **Settings** aligned to the handoff: FOV 104, sensitivity 2.40 on the 0.1-10 slider, ADS
  multiplier 0.72, crosshair gap/thickness/colour/dot, HUD scale, reduce-flashing.

## Deviations, flagged

1. **The announcement band was moved.** Its token position (`ANNOUNCE_Y = 180`) put it 40px
   inside the no-UI zone. Rule 3 - the centre 900x500 belongs to the crosshair - outranks an
   offset, so the block is anchored to *end* clear of the zone instead. A test now guards every
   cluster against intruding on the centre.
2. **Archivo ships as woff2, not ttf.** Google Fonts serves the variable face as woff2; Godot 4
   loads it natively, so only `FONT_DISPLAY`'s extension changes.
3. **Reduce-flashing is wired but only covers the low-health pulse.** The low-ammo blink still
   needs the same treatment.
4. **Weapon viewmodels are still one placeholder box.** The four silhouettes in
   SPEC-VIEWMODELS 1.2 are modelling work, not UI work.
5. **Arena telegraphing is not rebuilt yet.** Grapple anchors, bounce pads, spawn doors and
   pickups still use their Phase 2-3 colours rather than the one law
   (cyan usable / acid hazard / amber take / magenta spawn) and the shared state-enum scene.
6. **Shop, wave-complete, menus and settings screens are not restyled yet.** They work, but
   they predate the theme.

## Still open, in the handoff's priority order

- Arena element telegraphing and colour law (priority 5)
- Shop and wave-complete screens (priority 6)
- Menus and settings (priority 8)
- Lower third for scripted Host beats, and the arena jumbotrons (priority 9)

## Testing

154 tests. New: token and font integrity, the no-UI zone law, HUD wiring and state changes, and
spec conformance for the values that live outside the token file.

Two tests caught real problems rather than confirming the code: the announcement band intruding
on the no-UI zone, and Ranger and Healer sharing a silhouette rectangle - which turned out to be
the missing halo, not a bad number.
