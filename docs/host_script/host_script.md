# MAYHEM — Host VO recording script

Generated by `tools/export_host_script.gd` from `data/host/host_catalog.tres`.
Re-run the tool after editing the catalog; do not hand-edit this file.

**Format:** deliver each line as a mono `.ogg`, named exactly as shown (case-sensitive),
in a folder we'll tell you separately. **Deliver `PUNCHLINE` lines with extra emphasis** —
in game they get the full-screen treatment instead of a subtitle rail, so a flat read
undersells them. `WARNING` lines carry a threat the player has to react to; read them
with urgency, not humor. Everything else (`STANDARD`) is dry stadium-announcer sarcasm —
think a boxing ring announcer who has seen this exact fight a thousand times.

**Do not reorder or skip lines within an occasion.** The filename is tied to line
order; an out-of-order recording silently plays the wrong line in game.
