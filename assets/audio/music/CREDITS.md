# Music credits

## Tracks in the game

Six tracks, assigned to phases in `data/audio/music_playlist.tres`:

| Track | Where it plays |
|---|---|
| `Anthem_of_the_Week.mp3` | Menu |
| `A_New_Monstrosity.mp3` | Run (waves and shop) |
| `Johnny_Five.mp3` | Run |
| `Through_the_Paces.mp3` | Run |
| `Zebra_Freak.mp3` | Run |
| `Dont_Forget_About_Us.mp3` | After a run ends |

> **PENDIENTE, y sólo lo puede completar quien las trajo.** Falta, por track:
> título, compositor o licenciante, licencia (CC-BY, una licencia comprada, una
> composición propia) y el texto de atribución que esa licencia exija mostrar
> en el juego o en los créditos. Sin eso no se puede publicar: la licencia viaja
> con cada build. Si son originales, alcanza con decirlo acá y firmarlo.

## Placeholders (ya no están)

`menu.wav`, `combat.wav` y `shop.wav` eran placeholders sintetizados por
`tools/generate_placeholder_music.py` (Python de stdlib, semilla fija). Salieron
del repo cuando entraron los tracks de arriba. El generador queda por si hace
falta volver a un bed provisorio; los SFX siguen saliendo de
`tools/generate_placeholder_sfx.py`.
